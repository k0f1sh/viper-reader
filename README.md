# ViperReader

ViperReader は、手動で登録した技術系 RSS フィードを、**2010年代前半の 2ch ニュー速VIP板およびまとめブログ風の文体と UI** に変換して閲覧する、自分専用のインテリジェント情報収集 Electron デスクトップアプリです。

真面目な最新技術情報を、ネットのジャンクフードのようなエンタメ感覚で日々ブラウズし、自発的な技術インプットを促進することを目的とします。

## 📸 アプリケーションの構成 (3ペイン構成)

かつての 2ch ブラウザ（JaneStyle やギコナビ等）をオマージュしたレトロな 3 ペイン構成を採用しています。

* **左ペイン (板一覧)**: ユーザーが登録した RSS ソース一覧。板一覧やお気に入りリストのように扱います。
* **右上ペイン (スレタイ一覧)**: 選択した RSS ソースの記事一覧。元のタイトルを生タイのままではなく、Gemini によって 2010 年代 VIP のスレタイ風（例: `【ガチ】○○が凄すぎてワイ無事死亡ｗｗｗｗ`）に変換して表示します。
* **右下ペイン (スレッド表示)**: 選択した記事の概要を、まとめブログの抜粋レス（`1:`、`4:`、`12:` など飛び飛びのレス番）形式で表示します。背景色はほんのり青白いレトロな画面（`#efeffc`）です。

## ✨ 主な機能

### 1. VIP風スレタイ変換 & まとめ風要約 (Gemini AI)
* **スレタイ自動変換**: RSS から取得した記事タイトルを、技術的な意味を保ったまま VIP 風にネタ化して表示します。
* **手動スレッド生成**: スレタイをクリックすると、最初は1番目のレス（スレタイ）のみ表示されます。下部にある「読み込む（生成）」ボタンをクリックしたタイミングで、Gemini が元記事の本文を元に3行でくだけた VIP 口調で要約・議論スレを自動生成します。
* **再生成機能**: スレッドのヘッダーにある「再生成」ボタンから、いつでも 2 番以降のレスを再生成できます。

### 2. マナーを守ったインテリジェント・スクレイピング
* **`robots.txt` への厳格な準拠**: 
  - 本文スクレイピングを行う前に、相手サイトの `robots.txt` を取得し、すべての一般的なボット向けの共通制限（`User-agent: *`）に準拠しているか検証します。
  - クローラーアクセスが禁止（Disallow）されている場合は、マナーを守ってアクセスをスキップし、当時の「2get」などのフォールバックセリフとともに取得不可として安全に終了します。
* **ローカルキャッシュによる負荷最小化**:
  - スクレイピングした本文や、Gemini で生成したスレッド内容はすべて SQLite データベースに保存されます。同じ記事を何度も読み直す際、相手サーバーや Gemini API へ重複した無駄なリクエスト・負荷をかけることはありません。
* **通信時のブラウザ偽装**:
  - HTTP リクエスト時の User-Agent は、一般的な Chrome ブラウザのものを使用し、Cloudflare などのWAFによる機械的ブロックを回避します（判定自体は `*` ボットとして robots.txt を遵守します）。

### 3. レトロな専ブラ風の操作性とUI
* **境界幅・カラム幅の自動記憶**: 
  - スレタイ一覧とスレッド表示の分割比率（高さ）や、スレタイ一覧の各カラムの幅をドラッグして変更すると、マウスを離した瞬間に自動的に SQLite に保存され、次回起動時に再現されます。
* **専ブラ風アンカーリンク機能**:
  - レス内に `>>2` などのアンカーがある場合、クリック可能なリンクになります。クリックすると該当レスへスムーズスクロールし、かつてブラウザのように背景が一瞬薄黄色に光るフェードアウト（ハイライト）演出が走ります。
  - スレタイと「再生成」ボタンが含まれるスレッドヘッダーは最上部に固定（fixed）され、スレッドをスクロールしても流れません。
* **板ごとの住民設定（カスタムプロンプト）**:
  - 購読フィード（板）ごとに「この板の住民はヌクモリティが高い」「煽り禁止」といったカスタムプロンプト（住民設定）を保存でき、板の個性をコントロールできます。
* **詳細な統計情報 & 取得履歴**:
  - API のトークン利用量、RSS 更新履歴のほか、**元記事の取得履歴（取得サイズ、所要時間、robots.txt 判定結果などのログ）**をグラフィカルな2ch調UIで確認できます。

## 🛠 技術スタック

* **アプリ基盤**: Electron + TypeScript
* **ビルドツール**: Vite
* **UI**: 素の HTML, CSS, TypeScript (React 等の重厚なフレームワークや TailwindCSS はあえて不使用)
* **LLM SDK**: `@google/genai` (モデル: `gemini-3.1-flash-lite`)
* **RSS解析**: `rss-parser`
* **本文スクレイピング・抽出**: `jsdom` + `@mozilla/readability`
* **データベース (キャッシュ & 設定保存)**: SQLite (`node:sqlite` によるネイティブサポート)

## 🚀 セットアップ & 起動方法

### 前提条件
* Node.js (v22 以上推奨)

### 1. 依存パッケージのインストール
```bash
npm install
```

### 2. 環境変数の設定
プロジェクトのルートディレクトリに `.env` ファイルを作成し、Gemini API キーを設定します（`.env.example` を参考にしてください）。

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 開発モードでの起動
```bash
# 開発サーバーおよび Electron の起動
npm run dev:app
```

### 4. パッケージング・ビルド
```bash
# 本番向けビルド
npm run build
```
