# ViperReader

ViperReader は、手動で登録した技術系 RSS フィードを、2010年代前半 of 2ch ニュー速VIP板およびまとめブログ風の文体と UI に変換して閲覧する、個人用 Electron デスクトップアプリです。

真面目な最新技術情報を、エンタメ感覚で日々ブラウズし、自発的な技術インプットを促進することを目的としています。

![ViperReaderのスクリーンショット](./screenshot/viper-reader-v1.png)

---

## 📸 画面構成 (3ペイン)
かつての 2ch ブラウザをオマージュしたレトロな 3 ペイン構成です。

- **左ペイン (板一覧 / お気に入り)**: 購読中の RSS フィード一覧と、お気に入りスレッドのリスト（折りたたみ対応）。
- **右上ペイン (スレタイ一覧)**: Gemini によって 2010年代 VIP のスレタイ風に変換された記事一覧。
- **右下ペイン (スレッド表示)**: 選択した記事のまとめブログ風実況スレッド。

---

## ✨ 主な機能

- **スレタイ・レスの VIP 風自動変換**: 記事タイトルを VIP 風スレタイに変換し、本文から実況レス調の要約を自動生成します。
- **AI住民との対話・続きの生成**: ユーザー自身の書き込みや、スレ末尾の「再読み込み(続きのレス生成)」ボタンにより、AI住民同士の掛け合いをさらに進めることができます。
- **レスプレビューポップアップ**: レス番号や `>>X` のアンカーをホバーした際に、内容をポップアップ表示します（ポップアップ上へマウスを乗せることで表示の維持が可能）。
- **お気に入り機能**: 気になるスレッドをブックマークし、左ペインのお気に入りリストから直接開くことができます。
- **板ごとの住民設定**: 板（フィード）ごとにカスタムプロンプトを設定し、住民の個性をコントロールできます。
- **レス生成AIモデルの切り替え**: `3.5 flash` と `3.1 flash lite` をメニューバーからいつでも切り替え可能です。
- **SQLite キャッシュによる負荷最小化**: 取得した本文や生成されたレス、要約はすべてローカルに保存され、無駄な API 消費や配信元への負荷を防ぎます。
- **robots.txt の遵守**: 配信元サイトの `robots.txt` クローラー制限を遵守して動作します。

---

## 🛠 技術スタック

- **アプリ基盤**: Electron + TypeScript
- **フロントエンド**: HTML / CSS / TypeScript (React / Vite)
- **AI統合**: `@google/genai` (モデル: `gemini-3.1-flash-lite` / `gemini-3.5-flash`)
- **データベース**: SQLite
- **主なライブラリ**: `rss-parser`, `cheerio`

## 🚀 セットアップ & 起動方法

### 前提条件
- Node.js (v22 以上推奨)

### 1. パッケージのインストール
```bash
npm install
```

### 2. 環境変数の設定
ルートディレクトリに `.env` ファイルを作成し、Gemini API キーを設定します。
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. 開発モードでの起動
```bash
npm run dev:app
```

### 4. ビルド
```bash
npm run build
```
